SENAI PARKING — PROTÓTIPO

Abra index.html no navegador.

Páginas:
- index.html -> acesso
- painel.html -> painel geral
- vagas.html -> visualização dos mapas e vagas
- agendar.html -> seleção/agendamento no mapa
- minhas-vagas.html -> gestão das reservas
- sobre.html -> informações do projeto

As imagens dos estacionamentos estão em assets/.
As reservas ficam no localStorage do navegador, apenas para demonstração.
